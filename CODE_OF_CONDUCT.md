# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate as pessoas com respeito, discuta a ideia e não quem a trouxe, e aceite revisão
com boa-fé. Assédio, ofensa e ataque pessoal não têm lugar aqui.

Saúde pública é um assunto que mexe com as pessoas. Discordância sobre política de saúde é
bem-vinda nas issues quando ajuda o jogo; propaganda partidária, não.

Para relatar um problema de conduta, fale com o mantenedor pelo perfil
[@jvitorcarvalho](https://github.com/jvitorcarvalho).
